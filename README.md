## Executar

No terminal do Codespaces:

```bash
flutter pub get
flutter analyze
flutter test
```

Em Run and Debug, selecione **Rodar App Flutter (Web Preview)** e pressione F5.

Cadastre uma conta antes de testar o login.

## Entrega

```bash

```
